本次四窗口期间采样中位数为 688.78 MiB / 385.86 MiB，但采样开始时第三个子窗口可能仍在初始化，标记为不稳定，不用于优化前后比较或计算回收收益。优化前关闭阶段误打开媒体窗口，也没有有效的同场景关闭前后对照。原始摘要分别以 `after-one`、`after-four-unstable`、`after-close` 命名保存。
