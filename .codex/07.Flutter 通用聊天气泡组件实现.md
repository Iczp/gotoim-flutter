# Flutter 通用聊天气泡组件实现

## 1. 目标

实现一个统一的 Flutter 聊天气泡组件 `ChatBubble`。

组件只负责：

- 气泡外形
- 左右尾巴
- 圆角
- 背景色
- 内容裁剪
- 边框
- 阴影
- Padding
- 尾巴位置
- 点击 / 长按事件

组件不关心消息具体类型。

需要支持：

- 文本
- 图片
- 视频
- 语音
- 文件
- 位置
- 名片
- GIF
- 其他自定义 Widget

所有消息类型都通过：

```dart
ChatBubble(
  child: ...
)
```

复用统一气泡外形。


含义：

```text

right
自己发送

none

```


# 4. 尾巴实现要求

不要使用简单三角形：

```dart
lineTo(...)
```

不要做传统尖三角气泡。

要求使用：

```text
圆角矩形
+
圆 A
-
圆 B
```

实现。

具体：

```dart
PathOperation.union
```

将圆 A 与气泡主体合并。

然后：

```dart
PathOperation.difference
```

使用圆 B 挖空。

两个圆弧的交点形成尖锐尾巴。

要求尾巴：

- 尖端明显
- 两侧为圆弧
- 不能像普通三角形一样生硬
- 左右完全镜像
- 图片、视频等媒体内容也能直接裁出尾巴

------

# 5. 尾巴位置

尾巴必须支持三个基础位置：

```dart
enum ChatBubbleTailAlignment {
  top,
  center,
  bottom,
}
```

另外必须支持：

```dart
offset
```

进行 Y 轴微调。

定义规则：

```text
offset > 0
向下移动

offset < 0
向上移动
```

例如：

```dart
ChatBubbleTail(
  alignment: ChatBubbleTailAlignment.top,
  offset: 8,
)
```

表示：

```text
顶部位置 + 向下 8
```

例如：

```dart
ChatBubbleTail(
  alignment: ChatBubbleTailAlignment.center,
  offset: -10,
)
```

表示：

```text
垂直居中 - 向上 10
```

例如：

```dart
ChatBubbleTail(
  alignment: ChatBubbleTailAlignment.bottom,
  offset: -6,
)
```

表示：

```text
底部位置 - 向上 6
```

# 6. ChatBubbleTail

实现类似：

```dart
@immutable
class ChatBubbleTail {
  final bool enabled;

  /// 尾巴占用横向空间
  final double width;

  /// 尾巴圆弧半径
  final double radius;

  /// top / center / bottom
  final ChatBubbleTailAlignment alignment;

  /// 在基础位置上的 Y 偏移
  ///
  /// 正数向下
  /// 负数向上
  final double offset;

  /// top / bottom 与边缘的安全距离
  final double edgeInset;

  /// 挖空圆半径
  ///
  /// null 时自动计算
  final double? cutRadius;

  /// 挖空圆向气泡外部移动距离
  final double cutOutsideOffset;

  /// 第二个圆相对于第一个圆的 Y 偏移
  ///
  /// 主要用于调整尾巴尖锐程度
  final double cutYOffset;

  const ChatBubbleTail({
    this.enabled = true,
    this.width = 10,
    this.radius = 14,
    this.alignment = ChatBubbleTailAlignment.bottom,
    this.offset = 0,
    this.edgeInset = 2,
    this.cutRadius,
    this.cutOutsideOffset = 1,
    this.cutYOffset = -7,
  });

  const ChatBubbleTail.none()
      : enabled = false,
        width = 0,
        radius = 0,
        alignment = ChatBubbleTailAlignment.bottom,
        offset = 0,
        edgeInset = 0,
        cutRadius = null,
        cutOutsideOffset = 0,
        cutYOffset = 0;
}
```

# 7. 尾巴 Y 坐标计算

统一实现方法：

```dart
double resolveTailCenterY({
  required Size size,
  required ChatBubbleTail tail,
  required double radius,
}) {
  double y;

  switch (tail.alignment) {
    case ChatBubbleTailAlignment.top:
      y = tail.edgeInset + radius;
      break;

    case ChatBubbleTailAlignment.center:
      y = size.height / 2;
      break;

    case ChatBubbleTailAlignment.bottom:
      y = size.height -
          tail.edgeInset -
          radius;
      break;
  }

  y += tail.offset;

  return y
      .clamp(
        radius,
        size.height - radius,
      )
      .toDouble();
}
```

需要保证异常参数不会导致尾巴完全跑出组件。

不要同时再维护：

```text
centerY
bottomOffset
```

等其他位置系统。

统一只使用：

```text
alignment
offset
edgeInset
```

# 10. 为什么媒体不能预留 Tail Space

文本：

```text
◀ 气泡文字内容
```

需要避免文字进入尾巴区域，所以：

```dart
reserveTailSpace: true
```

图片：

```text
图片本身直接成为气泡形状
```

需要：

```dart
reserveTailSpace: false
```

否则图片左侧/右侧会出现一条难看的空白。

图片应该直接：

```text
Image
 ↓
ClipPath
 ↓
完整裁出气泡 + 尾巴
```

# 13. Path 生成流程

首先计算主体。

左尾巴：

```dart
Rect.fromLTRB(
  tailWidth,
  0,
  size.width,
  size.height,
)
```

右尾巴：

```dart
Rect.fromLTRB(
  0,
  0,
  size.width - tailWidth,
  size.height,
)
```

然后：

```dart
final bodyPath = Path()
  ..addRRect(...);
```

计算：

```dart
final cy = resolveTailCenterY(...);
```

------

# 14. 外圆

左：

```dart
final outerCenter = Offset(
  radius,
  cy,
);
```

右：

```dart
final outerCenter = Offset(
  size.width - radius,
  cy,
);
```

然后：

```dart
final outerCircle = Path()
  ..addOval(
    Rect.fromCircle(
      center: outerCenter,
      radius: radius,
    ),
  );
```

合并：

```dart
var result = Path.combine(
  PathOperation.union,
  bodyPath,
  outerCircle,
);
```

------

# 15. 挖空圆

计算：

```dart
final cutRadius =
    tail.cutRadius ??
    radius + 1;
```

左：

```dart
final cutCenter = Offset(
  -tail.cutOutsideOffset,
  cy + tail.cutYOffset,
);
```

右：

```dart
final cutCenter = Offset(
  size.width +
      tail.cutOutsideOffset,
  cy + tail.cutYOffset,
);
```

创建：

```dart
final cutCircle = Path()
  ..addOval(
    Rect.fromCircle(
      center: cutCenter,
      radius: cutRadius,
    ),
  );
```

挖空：

```dart
result = Path.combine(
  PathOperation.difference,
  result,
  cutCircle,
);
```

返回：

```dart
return result;
```

# 16. 尾巴参数含义

主要参数：

```text
alignment
尾巴顶部 / 中间 / 底部

offset
上下微调

edgeInset
与顶部、底部的基础间距

width
尾巴占用横向宽度

radius
尾巴整体圆弧大小

cutRadius
挖空圆大小

cutOutsideOffset
第二个圆向外偏移

cutYOffset
两个圆上下错位
```

其中调节尖锐程度主要使用：

```dart
cutYOffset
```

初始推荐：

```dart
cutYOffset: -7
```

参考：

```text
-4
比较圆润

-6 ~ -7
正常

-8 ~ -9
比较尖

-10 ~ -11
更加尖锐
```

最终以实际 UI 效果为准。


# 28. 性能要求

聊天列表可能存在大量消息。

注意：

- `CustomClipper.shouldReclip` 必须正确比较参数
- 参数不变时不要重复裁剪
- 不要在 `build` 中进行无意义复杂对象创建
- 不要使用 `IntrinsicWidth/IntrinsicHeight` 实现普通消息布局
- 图片尺寸提前计算
- 不要因为气泡组件影响虚拟列表性能

Path 计算应保持简单。

------

# 29. 极端尺寸处理

需要处理：

```text
很短的文字
单个 Emoji
很矮的语音消息
非常窄的气泡
超大图片
```

`radius` 不能超过当前尺寸合理范围。

例如：

```dart
final radius = math.min(
  tail.radius,
  math.max(
    1.0,
    size.height / 2,
  ),
);
```

尾巴 Y 坐标必须 clamp。

不能产生：

```text
NaN
负尺寸
Path 异常
尾巴完全脱离主体
```
